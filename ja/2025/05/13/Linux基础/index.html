Linux 基础：服务器上的常用命令

前言

课程最后一课是 Linux，理由很直接：服务器上跑的基本都是 Linux。前面写的 Django 项目最终要部署到 Linux 服务器，用的就是这些命令——cd 进项目目录、vim 改配置、chmod 给静态目录权限、ps 查进程、kill 杀掉卡住的 uwsgi。

这篇按课件顺序整理：先建立「目录树」和「命令格式」两个直觉，再是文件操作、用户与权限、查找与文本处理、远程管理、系统信息和 vim。课程是在 VMware 里装的 Ubuntu 虚拟机练的。

一、先建立两个直觉

1. 没有盘符，只有一棵树。

Windows 打开「我的电脑」看到 C、D、E 多个盘符，每个盘符各自是一棵树的根；Linux 只有一个根目录 /，所有设备、文件都挂在这棵树下（/home 是用户家目录，/etc 是配置，/var 是可变数据，/usr 是程序……）。

2. 命令都是「命令 + 选项 + 参数」的格式。

查帮助有两种方式，选项和参数都忘了就查：

几个能省大量时间的技巧（课件里的「学习技巧」）：

  • 命令不用背：Tab 键补全，有歧义按两次 Tab 会列出候选；
  • 上下箭头翻出用过的命令，history 看全部历史；
  • ctrl+c 取消当前命令（比如 ping 停不下来时）；
  • ctrl+u 清空已输入的内容。

二、文件与目录操作

命令 作用 常用选项
ls 查看目录内容 -a 显示隐藏文件、-l 列表详情、-h 人性化大小、-R 递归
cd 切换目录 . 当前、.. 上级、~ 家目录、- 上次目录
touch 新建文件 可一次建多个
mkdir 新建目录 -p 递归创建（mkdir -p a/b/c）
rmdir 删除目录 只能删空目录
rm 删除文件/目录 -r 递归、-f 强制
mv 移动 / 重命名 同目录下移动就是重命名
cp 复制 -r 复制目录、-i 覆盖前询问
cat 查看/合并文件 -n 行号、-s 压缩空行、-b 非空行编号
more 分页查看 内容多的文件用它
history 历史命令 history -c 清空记录
sudo 以 root 权限执行 Ubuntu 默认不允许 root 直接登录

⚠️ rm -rf 是这套命令里最危险的一条：Linux 下没有回收站，删掉就找不回来。执行前一定 pwd + ls 确认自己在哪、要删什么。

三、用户、用户组与权限（重点）

用户与用户组

两条容易踩的规则（课件特别提示）：

  1. 创建用户时会默认创建一个和用户名同名的组；
  2. 新创建的用户没有 sudo 权限，需要把它加到 adm、sudo 这两个组里才拥有 sudo 权限，否则你只能一直 su 过去。

用户信息存在 /etc/passwd，组信息在 /etc/group，可以直接 grep 查：

权限：三组人 + 三种权限

ls -l 看到的这一串就是权限：

  • 三组分别对应 u（所有者）/ g（所属组）/ o（其他人）；
  • 每组三个位置依次是 r（读）/ w（写）/ x（执行）；
  • 数字表示法：r = 4，w = 2，x = 1，所以 rwx = 7、rw- = 6、r-- = 4。

chmod 755 拆开看就是：所有者 7（rwx）、所属组 5（r-x）、其他人 5（r-x）——这是目录和可执行脚本最常见的权限。

课件里那组练习值得照着做一遍（答案就是课上的命令）：

为什么部署时老要 chmod：nginx 要读静态文件目录，Django 要往 media 里写上传的图片，权限不对就会出现「文件明明在，就是 403/404」。部署课件里那句 sudo chmod 777 /var/www/myblog/static/ 就是为这个。

四、查找与文本处理

which / whereis：查命令在哪

which 在 $PATH 里搜索可执行文件（还会显示别名），whereis 还会列出帮助文档路径。

find：按条件找文件

选项 含义 例子
-name 按文件名 find /etc -name init*
-size 按大小（单位是块，512 字节=1 块） find /etc -size +10k
-user / -group 按所有者 / 所属组 find /home -user root
-mtime -atime -ctime 按天：修改 / 访问 / 属性变更 find /etc -mtime -1
-mmin -amin -cmin 按分钟（更常用） find /etc -amin -60
-type 按类型（f 文件、d 目录、l 链接） find /etc -type f
-inum 按 i 节点号 find . -inum 159341
-a / -o 逻辑与 / 或 find /etc -size +10k -a -size -20k
-exec / -ok 对结果执行命令（{} 代表结果，\; 结尾） find . -name "*.tmp" -exec rm -f {} \;

时间选项的记忆法（课件原话）：

  • change：属性被改过（所有者、权限）
  • access：被浏览过
  • modify：内容被改过
  • - 表示「多少时间之内」，+ 表示「超过多少时间」

课件提醒：尽量缩小查找范围，别一上来就 find /，又慢又占资源；实在要全盘找，选服务器压力小的时候。

locate：查数据库，快但可能不准

locate 是在文件数据库里查，所以快；但如果数据库没更新，新建的文件就查不到。而且系统在 /etc/updatedb.conf 里配了搜索限制（PRUNEFS、PRUNENAMES、PRUNEPATHS），某些路径本来就不会被收录——which、whereis 也遵守同样的限制。

grep：在文本里找内容

六、远程管理：ssh 与 scp

ssh：加密远程登录

Windows 下常用 Xshell 或 PuTTY 连接（它们只是图形化的 ssh 客户端）。

scp：跨主机传文件

Windows 上传下载文件可以用 WinSCP（图形化 scp）。部署 Django 项目时，「把项目传上服务器」这一步用的就是它。

七、系统信息与进程管理

命令 作用
date 查看系统时间
df -TH 查看磁盘分区与挂载情况
du -sh 目录 / du -h 文件 查看目录 / 文件大小
uname -a 内核、操作系统、CPU 信息（-r 内核版本、-m CPU）
top 实时进程与资源占用，按 q 退出
ps -ajx 查看所有进程状态
kill 进程号 / kill -9 进程号 结束进程（-9 强制、-15 温和）

top 的内存字段容易看混，记这三个就够：

  • VIRT：虚拟内存总量（= SWAP + RES）
  • RES：实际占用的物理内存
  • SHR：共享内存

进程状态：R 运行、S 睡眠、D 不可中断、T 停止、Z 僵尸。

⚠️ 1 号进程（init）是所有进程的祖先，不能被结束。

九、踩坑与易忘点

现象 原因 解决
Permission denied 当前用户没这个文件的权限 前面加 sudo，或 chmod 改权限
新用户不能用 sudo 没加入 sudo 组 usermod -a -G sudo,adm 用户名
rmdir 删不掉目录 它只能删空目录 用 rm -r
cp 目录报错 少了递归选项 cp -r
tar 报「文件是归档文件」 -f 没放在选项最后 写成 tar -zcvf x.tar.gz 文件…
ping 停不下来 默认无限发包 ctrl+c，或用 -c 10 限制包数
locate 找不到刚建的文件 文件数据库没更新 sudo updatedb
find / 卡很久 查找范围太大 指定具体目录，别从根目录找
改了配置没生效 没重启服务 service xxx restart 或重跑进程
kill 杀不掉 进程在内核态或需要权限 kill -9 + sudo；1 号进程杀不掉

小结

Linux 命令看起来又多又杂，其实可以按「四个问题」归类：

  1. 我在哪、这有什么 → pwd / ls / cd
  2. 我要动它 → mkdir / touch / cp / mv / rm，配合 chmod 管权限
  3. 我要找它 → find（按条件找文件）/ grep（按内容找行）/ which（找命令）
  4. 我要连它 → ssh 登录 / scp 传文件 / ps + kill 管进程 / df + top 看状态

真正常用的只有二十来条，剩下的用 --help 和 man 现查就行。课件里那句话我很有共鸣：常用命令不用死记硬背，用多了自然就记得了。
