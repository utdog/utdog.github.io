python高级编程

前言

基础语法解决的是“写得出来”，高级编程解决的是“写得像样”。这篇笔记记录我跨过入门阶段后重点啃的几块内容：闭包与装饰器、迭代器与生成器、上下文管理器、魔术方法、异常处理、并发模型和类型注解。每一节都尽量给出“为什么需要它”和“实际怎么用”，而不是只背语法。

一、从函数到一等公民

Python 里函数是对象，可以赋值、当参数、当返回值。这是后面所有高级特性的地基。

闭包

内层函数记住了外层函数的变量，即使外层已经返回：

闭包的价值在于“把状态藏在函数里”，不用定义类就能封装数据。

二、装饰器

装饰器本质是“接收函数、返回函数”的函数，用来在不改原代码的前提下加功能——日志、计时、鉴权、缓存都是它。

五、魔术方法

以双下划线开头结尾的方法是给解释器看的，实现它们能让自定义对象“用起来像内置类型”。

六、异常处理进阶

原则：只捕获你能处理的异常，不要写一个裸的 except: 把问题全吞掉；自定义异常能让调用方区分“业务错误”和“程序 Bug”。

七、并发：线程、进程与协程

graph TD
    A[任务类型] --> B{CPU 密集还是 IO 密集}
    B -->|CPU 密集| C[多进程 multiprocessing]
    B -->|IO 密集| D[多线程 threading]
    B -->|高并发 IO| E[协程 asyncio]
  • 多进程：绕开 GIL，真并行，适合计算密集型；进程间通信有开销。
  • 多线程：受 GIL 限制，同一时刻只有一个线程跑 Python 字节码，但 IO 等待时会释放，适合爬虫、文件读写。
  • 协程：单线程内的协作式并发，几万个任务也不怕，写起来要 async/await。

八、类型注解与数据类

注解不影响运行，但能让 IDE 和 mypy 提前发现问题。

@dataclass 自动生成 __init__、__repr__、__eq__，写数据容器时能省一大段样板代码。

九、值得背下来的标准库

模块 常用成员 用途
itertools chain groupby islice product 高效迭代器工具
functools lru_cache partial reduce 函数工具
collections Counter defaultdict deque namedtuple 好用的容器
pathlib Path 面向对象的路径操作，替代 os.path
json / csv load dump DictReader 数据读写
logging getLogger 比 print 更专业的日志

小结

高级编程的收益不在“代码短”，而在可维护：装饰器把横切逻辑抽走，生成器把内存压下来，上下文管理器保证资源不泄漏，类型注解让协作少踩坑。下一步是把这些技巧用到 Django 项目里——尤其是用装饰器做登录校验、用生成器做大批量数据导出。
