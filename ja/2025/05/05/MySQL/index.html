MySQL

前言

这篇笔记整理我学习 MySQL 的完整路径：从服务端的安装与连接，到库表设计、数据类型的选择，再到增删改查、约束与索引，最后用 Python 把数据库接进项目里。全文围绕一个“学生成绩管理”的小场景展开，一共三张表：学生表 student、课程表 course、成绩表 score。写下来既是复习，也方便以后直接抄。

一、MySQL 在项目里的位置

graph LR
    A[Navicat / 命令行 / PyMySQL] --> B[MySQL 服务端]
    B --> C[(InnoDB 数据文件)]
  • 客户端：负责发命令。图形化用 Navicat Premium，命令行用 mysql，代码里用 PyMySQL 这类驱动。
  • 服务端：真正干活的地方，监听 3306 端口，负责解析 SQL、加锁、事务和写磁盘。
  • 存储引擎：MySQL 8 默认 InnoDB，支持事务、行级锁、外键；另一常见的 MyISAM 不支持事务，现在基本不用。

记住一句话：表设计得好不好，决定了后面 80% 的痛苦。

二、安装与连接

安装时选 Developer Default 或 Server only 都可以，关键是记住 root 密码，并勾选“把 MySQL 加入环境变量”（否则命令行里得写完整路径）。

三、库与表的增删改（DDL）

DESC student; 随时可以看表结构，SHOW CREATE TABLE student; 能看到完整的建表语句。

四、数据类型怎么选

类型 占用 适用场景 备注
TINYINT 1 字节 年龄、状态值 无符号范围 0-255
INT 4 字节 主键、外键、计数 主键常用 INT UNSIGNED AUTO_INCREMENT
BIGINT 8 字节 大整数、雪花 ID 订单号这类别用 INT
DECIMAL(m,d) 变长 金额、成绩 精确小数，别用 FLOAT 存钱
VARCHAR(n) 变长 姓名、标题 按实际最大长度给，不要一律 255
CHAR(n) 定长 手机号、MD5 定长查询更快
TEXT 变长 文章正文 不能设默认值
DATETIME / TIMESTAMP 8/4 字节 时间 TIMESTAMP 会自动转时区，2038 年溢出
ENUM 1-2 字节 性别、状态 改动枚举值要改表结构

原则：够用就好。字段给得越小，一个数据页能放的行越多，查询越快。

六、约束与索引

约束是数据库帮你守住的数据底线：

索引是拿空间换时间：

几个容易踩的坑：

  • 索引不是越多越好，每个索引都会拖慢写入；
  • 在索引列上做运算或函数（WHERE YEAR(created) = 2025）会让索引失效；
  • LIKE '%关键字' 前置通配符同样用不上索引；
  • 区分度低的列（比如性别）单独建索引意义不大。

EXPLAIN 的结果里重点看 type（至少要到 range，ALL 就是全表扫描）和 rows（预估扫描行数）。

八、事务

转账、下单这类“要么全成功要么全回滚”的操作必须用事务：

事务有 ACID 四个特性：原子性、一致性、隔离性、持久性。InnoDB 默认隔离级别是 REPEATABLE READ，能避免脏读和不可重复读，但要注意间隙锁带来的并发下降。

九、Python 操作 MySQL（PyMySQL）

两个必须记住的点：

  1. 永远用参数化查询（%s 占位），拼接 SQL 就等于把 SQL 注入的大门敞开；
  2. 增删改之后要 commit()，否则连接一关数据就没了。

十、踩坑记录

报错 原因 解决
Access denied for user 'root'@'localhost' 密码错或没授权 检查密码；必要时 ALTER USER 重置
Unknown database 'school' 库没建或名字拼错 CREATE DATABASE 或 USE 正确的库
Incorrect string value: '\xF0\x9F...' 字符集不是 utf8mb4 库、表、连接三处统一改成 utf8mb4
Cannot add or update a child row 外键约束不通过 先插主表数据，或检查外键值
Lock wait timeout exceeded 有事务没提交，锁住了 查 SHOW PROCESSLIST，结束挂起的事务
中文显示成 ??? 客户端编码不对 连接串加 charset='utf8mb4'

小结

MySQL 的学习路线我总结成四步：会连 → 会建 → 会查 → 会优化。前两步靠记忆，后两步靠 EXPLAIN 和自己踩的坑。下一步打算把这三张表接到 Django 里，用 ORM 重写一遍同样的查询，对比一下手写 SQL 和 ORM 各自的代价。
