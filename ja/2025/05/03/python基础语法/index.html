    python基础语法

    前言

    在这篇“Python 基础语法”学习日志中，我将以“复习笔记”的形式，带着探索的心态，认真梳理和回顾 Python 语言的核心语法要点。你将看到我如何一步步从变量与数据类型入手，理解条件判断与循环结构的使用；如何用函数封装常用逻辑，以及面向对象编程中类与实例的基本概念。每一个示例都是我在动手实践中的心得记录，既包括简单的代码演示，也涵盖我在练习过程中遇到的小问题与思考方式。希望这篇前言能够为后续内容提供一个清晰的脉络，让我们一同在“学中记、记中学”的节奏里，扎实打好 Python 基础语法的根基。

    python的环境配置

    1.分辨电脑系统的位数

    安装对应位数的版本–一般市面上64/32（主流64）
    怎么查看“电脑系统的位数？”： 此电脑->属性->系统类型

    2.环境变量（path）

    此电脑->属性->高级系统设置->环境变量

    3.交互模式和脚本模式

    python有两种开发模式
    交互模式 --> 进入python环境/idle默认就是交互模式–>类似于人类对话,一问一答.代码是会马上执行的.变现形式为>>>
    优点:用起来比较方便,即问即答,适合测试一些小代码
    缺点:不能保存/修改
    脚本模式/文件模式 --> 新建一个文件来写代码,写好的代码可以保存起来反复使用.也可以修改
    优点:可以修改/保存

    4.idle

    idle 是python自带的开发工具。
    怎么打开IDLE:
    1.按下win键
    2.找到python软件
    3.找到idle
    4.右键–>更多–>打开文件所在位置
    5.直接复制到桌面 / 选中添加到桌面快捷方式

    在idle中如何新建文件
    快捷键 ctrl+n file --> new file --> ctrl + s 保存
    保存文件时.要选择 1.文件名 2.文件保存位置

    运行程序快捷键是f5
    run --> run module
    打开已经保存好的代码文件–>file -->open

    输入输出（IO）

    打印/输出 print

    把你想说的直接说出来

    基本格式

    输出不同类型的数据

    数字（整数、浮点数等）
    括号内直接写数字，不加引号

    字符串（中文、字母、符号）

    必须加引号（单引号、双引号皆可）

    多项内容拼接输出

    用逗号分隔，print会在每个项之间插入一个空格

    输入 input

    运行代码之后可自定义输入目标内容 向用户生成一条提示,然后获取用户输入的内容

    基本格式

    input(提示内容)

    注意事项

    括号内出现的 字符串 一定要加引号；
    数字、变量、表达式 则无需引号；
    多项输出时，用逗号分隔即可自动拼接并加空格。
    编写代码时必须切换成英文输入状态,否则会报错.特别是标点符号必须在英文状态下输入。
    input不能直接输出内容 括号里提示语句 不能直接写结果。

    默认情况下,print()函数每次都在新行上打印,这是由于 Python 文档中 print() 定义决定的

    注释

    不参与程序运行，仅供自己确定代码的功能
    也可应用于一段代码既不想用也不影响整体程序的情况

    单行注释

    在#后面的都被注释

    多行注释

    用一对三引号包裹着的内容被注释（单/双引号皆可）

    初识变量与基本数据类型

    在编程中，*变量（Variable）*就像一个带名字的容器，用来存储程序运行时需要反复使用的数据。将数据保存在变量里，不仅能让代码更简洁，也更易于维护和阅读。

    什么是变量？

    定义

    变量是可以改变的值，比如年龄、体重、账户余额等。

    内涵三要素

    ·数据类型（type）：例如整型、浮点型、字符串等；
    ·内存地址（id）：变量在计算机内存中的存放位置；
    ·值（value）：变量当前保存的数据内容。

    类比

    把变量想象成一个“仓库”，仓库类型对应数据类型，仓库地址对应内存地址，仓库里放的东西就是变量的值。

    变量命名规范

    ·由字母、数字和下划线组成（不推荐使用中文或其他符号）。
    ·不能以数字开头；
    ·严格区分大小写（Name ≠ name）；
    ·避免使用 Python 关键字（如 print、input）作为变量名；
    ·名称要“见名知意”，一眼就能看出用途。

    常见命名风格

    ·驼峰式：userName、UserAge
    ·下划线式：user_name、user_age

    变量声明与使用变量

    单个声明

    批量声明（逗号分隔）

    输出变量

    通过input赋值

    基础数据类型

    数值类型

    int：整数，如 age = 21
    float：浮点数，如 weight = 99.9
    bool：布尔值，只有 True （1） 或 False （0） ，注意首字母大写

    字符串类型

    用单、双、三引号包裹

    拼接：‘大牛’ + ‘666’
    重复：‘大牛’ * 5

    基本运算/赋值运算/比较运算/逻辑运算/成员运算 运算符

    基本运算符

    ·加减乘除： + - * /
    ·取余： %（如 10 % 3 == 1）
    ·整除： //（如10 // 3 == 3）
    ·幂运算： **（如4 ** 4 == 256）

    赋值运算符

    赋值符号的左边必须是一个变量名
    需要赋值给谁就把谁放在最左边

    = 赋值运算符 c = a + b(赋值运算符的程序是从右往左执行)
    += 加赋值 a+=b --> a=a+b
    -= 减赋值 a-=b --> a=a-b
    *= 乘赋值 a* =b --> a=a *b
    /= 除赋值 a/=b --> a=a/b
    %= 取余 a%=b --> a=a%b
    //= 整除 a//=b --> a=a//b
    * *= 幂 a**=b --> a=a**b

    比较运算符

    得到的结果为bool类型

    > 大于
    < 小于
    == 等于
    >= 大于等于
    <= 小于等于
    !=(英文符号) 不等于

    逻辑运算符

    代码 含义
    and 与 and左右两边的值必须都为真的时候才为真，否则为假
    or 或 or左右两边的值其中有一个真即为真，全假才为假
    not 非 就是将值为真的变成假的 假的变成真的

    成员运算符

    代码 含义
    in 判断成员是否在序列中
    not in 判断成员是否不在序列中

    运算符优先级

    先乘除后加减在判断

    （） 小括号
    ** 幂
    *，/，//，% 算术运算符
    +，- 算术运算符
    <, >,<=, >=,==,!= 比较运算符
    in not in 成员运算符
    not> and> or 逻辑运算符

    序列与下标/索引/切片/步长

    下标

    ·下标从0开始

    ·正向与负向下标

    索引

    ·含义：通过下标获取序列中指定位置的单个元素，就称为索引操作。
    基本语法变量名 = 序列名[下标]

    切片

    ·用途：一次性取出序列和一段连续的子序列
    基本语法变量名 = 序列名[起始下标:结束下标]
    ·起始可省略：默认为从0开始
    ·结束可省略：默认直到序列末尾
    ·结束下标不包含自身，只取到它的前一位

    步长

    ·含义：在切片基础上，按指定间隔跳跃取值
    基本语法序列名[起始:结束:步长]
    ·默认步长为1
    ·负步长可以实现反向切片

    列表（list）与元组（tuple）

    列表（可变序列）

    ·定义：用[]包裹，元素用逗号分隔

    ·嵌套列表

    元组（不可变序列）

    ·定义：用()包裹，元素用逗号分隔

    列表与元组的区别

    1.列表用[]可变；
    2.元组用()不可变。

    转义字符

    ·用途：在字符串中表示特殊含义或输出特殊字符
    ·常见转移：

    命令 作用
    \n 换行
    \t 制表符(通常是4个空格)
    \\ 输出反斜杠
    \' 输出单引号
    \" 输出双引号

    数据类型转换

    ·场景：不同类型间需要互相转换时使用。
    ·函数：

    命令 作用
    int(x) 转整形
    float(x) 转浮点数
    bool(x) 转布尔型
    str(x) 转字符串
    list(x) 转列表
    tuple(x) 转元组

    小结

    下标/索引 用于获取单个元素；
    切片/步长 用于批量或定步长获取子序列；
    列表/元组 均是序列，“可变”与“不可变”是它们最大的区别；
    转义字符 让字符串更灵活；
    类型转换 保证不同数据结构之间的互操作性。

    字符串进阶、路径与编码

    字符串进阶：格式化输出

    基本拼接（不推荐）

    f-string（最简便）

    在字符串前面加f或F，把变量写进{}中

    百分号占位符

    用%加类型标志，占位后再传入元组

    命令 作用
    %s 字符串
    %d 整数
    %f 浮点

    str.format()方法

    与占位符类似，使用{}占位，调用.format()填入值，可按位置或名称映射

    绝对路径与相对路径

    ·绝对路径：从磁盘根开始的完整路径

    ·相对路径：基于当前脚本所在目录的简化路径，同目录下可以直接写文件名

    字符编码（Encoding）

    计算机底层用 0 和 1 存储信息，字符编码 将二进制与人类可读字符相互映射。
    ·ASCII（1963）：仅包含英文、数字、符号。
    ·GBK（1995，中文大陆）、Big5（繁体）等区域标准。
    ·Unicode：收录全球上万字符，但单字符占空间大。
    ·UTF-8：最主流的变长编码，兼容 ASCII，节省空间。
    查看/转换

    提示：文件读写时，需以脚本编码（通常 UTF-8）打开，否则可能出现乱码。

    流程控制语句

    程序的三大执行流程
    ·顺序结构：代码按书写顺序自上而下、从左到右依次执行，若遇错误则终止后续执行。
    ·选择结构（分支结构）：根据条件真／假执行不同分支的代码。
    ·循环结构：在条件满足时重复执行某段代码，直至条件不再满足退出。

    缩进与代码块

    ·Python用缩进（Tab/四个空格）表明代码块归属：同一级缩进视为同一个块，
    块内再缩进则视为子块。
    ·建议始终使用一致的缩进方式，避免混用空格与Tab。

    选择结构（if系列）

    真假判断：Python 中以下视为假：0、空序列 []/()/‘’、空字典 {}、None；其他均视为真。

    双分支

    多分支

    循环结构

    while循环

    ·基本用法：先判断条件，再决定是否执行循环体
    ·需手动更新：放置无限循环

    ·死循环：while True:或while 1:，若无break，则永不停止。

    break与continue

    ·break：跳出当前循环，结束整个循环。
    ·continue：跳过本次循环体，进入下一次条件判断。

    pass占位

    ·当语法必须有代码但暂不实现功能时，使用pass防止报错

    for循环

    ·用于遍历可迭代对象（字符串、列表、元组、字典、集合）或固定次数（range）。

    嵌套示例

    ·分支嵌套：可以实现简单文字游戏

    ·循环嵌套：生成矩阵或方阵

    小结

    ·顺序、分支、循环 是程序的三大骨架；
    ·良好的缩进习惯是 Python 可读性与正确性的基础；
    ·掌握 if、while、for 及其控制语句 (break/continue/pass)，即可编写灵活多变的执行流程。
