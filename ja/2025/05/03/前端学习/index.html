前端VSC

前言

在这里，我将以复习笔记的形式，记录自己在前端世界中的学习过程：从最基础的 HTML 语义化标签，到 CSS 布局与响应式设计的基本思路；从 JavaScript 的初步 DOM 操作，到逐步接触 ES6+ 语法与模块化开发的尝试。每一部分都不是“我已掌握”，而是“我在学习”：我会写下自己动手实践的步骤、遇到的问题与解决思路，以及在反复实验中一点点加深的理解。无论是刚开始摸索时的疑问，还是回顾巩固时的关键点，都将真实呈现在博客中。这样的学习记录，既能帮助我自己回顾知识脉络，也能为同样在路上的你提供思考路径和参考。让我们一起，以“学中记、记中学”的心态，不断夯实前端基础，共同进步。
如有错误/问题可以在GitHub找到我。

关于本文的范围（补记）

这篇是前端知识的总体概览，写于我系统看课件之前。后来我按课件《前端 day01–day22》另写了一组更贴近课堂笔记的系列：《前端入门：HTML》、《前端入门：CSS》、《JavaScript 基础》、《jQuery 与 Bootstrap》、《贪吃蛇与 Ajax》。

对照课件后需要说明清楚——课件没有覆盖本文的以下部分：Grid 网格布局、JavaScript 异步编程（Promise / async-await / fetch）、工程化与性能优化（构建工具、缓存策略、will-change）、现代框架与前沿技术（React / Vue / CSS 容器查询）。这几节属于我的自学扩展，不是课程内容。

反过来，课件里讲得很扎实、而本文没有展开的东西（选择器权重链、外边距合并与 BFC、清除浮动四法、精灵图与图标字体、排他思想、原生 tab 栏、jQuery 选择器），建议直接看上面那组系列文章。
