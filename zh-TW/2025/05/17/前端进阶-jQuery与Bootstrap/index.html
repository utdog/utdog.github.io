前端进阶：jQuery 与 Bootstrap

前言

上一篇写原生 JS 时，为了给一排按钮做"排他"效果，写了两个 for 循环嵌套；为了开关灯，写了一大串 className 判断。

jQuery 的口号是 write less, do more（写得少，做的多，效果更好）——它把这些常用操作都封装成了一行代码。课件 day20 就是讲它，顺便讲了 Bootstrap（一个现成的 CSS 框架）。

说明：这篇依据的是课件 day20 的案例代码（该天没有 笔记 目录），代码片段都来自案例文件。

一、jQuery 是什么，怎么引入

jQuery 是一个 JS 库（不是框架）：把原生 JS 里最常用、最啰嗦的操作（找元素、绑事件、改样式、发请求、做动画）打包成函数，用一个 $ 符号暴露出来。

二、事件与 this

jQuery 的事件名都不带 on：

原生 jQuery
onclick click()
ondblclick dblclick()
onmouseover mouseover()
onmouseout mouseout()
onfocus / onblur focus() / blur()

最容易踩的一点：jQuery 的事件处理函数里，this 指向的仍然是原生 DOM 元素，不能直接调 jQuery 方法，必须用 $(this) 包一层才变成 jQuery 对象。

三、基本效果（动画）

方法 作用
show() 把隐藏的显示出来
hide() 把显示的隐藏
toggle() 切换显示 / 隐藏
slideUp() 上滑（收起）
slideDown() 下滑（展开）
slideToggle() 切换滑动

这些方法还能带参数控制速度：$("div").slideDown(500)（单位毫秒）。

html() innerHTML 取 / 设置内容，会解析标签
text() innerText 取 / 设置文本，不解析标签
val() value 取 / 设置表单元素的值

六、选择器

jQuery 的选择器和 CSS 基本一模一样，只是外面包了一层 $("...")。

基本选择器

写法 说明
$("div") 标签选择器
$("#btn") id 选择器
$(".demo") 类选择器
$("*") 通配符，获取所有元素
$(".demo,.test") 并集选择器（逗号）
$("li p") 后代选择器（空格）

过滤选择器（冒号开头）

写法 说明
$("li:first") 第一个 li
$("li:last") 最后一个 li
$("li:even") 索引为偶数的元素（0 开始，所以是第 1、3、5 个）
$("li:odd") 索引为奇数的元素
$("li:eq(2)") 第 3 个 li（索引从 0 开始）

:even / :odd 是按索引算的，和直觉相反——even 选到的是"第 1、3、5 个"。隔行换色时用 tr:even 或 tr:odd 都行，只要看清楚起手是哪一个。

筛选选择器（带括号的方法）

写法 说明
.eq(index) 获取第 index 个元素
.parent() 查找父级
.children() 查找孩子
.siblings() 查找除自己以外的所有兄弟

层级选择器

写法 说明
$("li > p") 子代选择器，只选儿子，不含后代
$(".one + li") 紧邻选择器，选 .one 后面紧挨着的那一个兄弟
$(".one ~ li") 兄弟选择器，选 .one 后面所有的兄弟

七、Bootstrap：现成的样式框架

Bootstrap 是 Twitter 开源的 CSS 框架（案例用的是 bootstrap-3.3.0-dist，还附了官方手册 .chm 和 bootstrap_3_官方手册_需要ie9+.chm）。用法是：引入它的 CSS，然后给标签加它规定好的类名。

按钮

类名是有套路的：btn 必须有（基础样式），后面再接尺寸（btn-lg / btn-sm / btn-xs）和颜色（btn-danger 红、btn-info 蓝、btn-warning 黄、btn-success 绿），btn-block 让它变成块级（占满一行）。

有意思的是 input 和 a 标签也能加 btn 类变成按钮——这就是"样式与标签解耦"的好处。

表单

  • form-group：一组表单控件（负责下边距等间距）；
  • form-control：输入框的统一样式（宽度会变成 100%）；
  • help-block：灰字的提示文字；
  • checkbox：勾选框的容器。

表格

类名 效果
table 基础表格样式（必须有）
table-striped 斑马纹（隔行变色）
table-bordered 加边框
table-hover 鼠标经过行高亮

隔行换色以前要用 JS 循环 + nth-child 或取余判断，加个 table-striped 类就完事了——这也是框架的典型价值。

八、踩坑速查

现象 原因 解决
$ is not defined 没引入 jQuery，或引入顺序不对 jQuery 必须在自己的脚本之前引入
this.css is not a function this 是原生 DOM 对象 用 $(this)
addClass(".cls") 没效果 类名前面多加了点 写 addClass("cls")
元素找不到，jQuery 操作没反应 脚本执行时元素还没渲染 放进 $(function(){}) 入口函数
只改了一个元素，其他没变 jQuery 选择器选中的是集合 集合会自动批量操作，不用循环；要单独操作就用 .eq(i)
:even 选中的不是"偶数行" 索引从 0 开始 记住 even 是索引偶数
Bootstrap 的 JS 组件不工作 没引 jQuery 或引到了它后面 顺序：jquery → bootstrap

小结

jQuery 的核心其实就是三件事：

  1. $("选择器") 找元素——选择器语法和 CSS 一样，选中集合会自动批量操作，省掉了 for 循环；
  2. $(元素).事件(function(){}) 绑事件——事件名不带 on，回调里用 $(this) 操作自己；
  3. .方法() 改内容/样式/做动画——html()/text()/val() 对应原生三个属性，css() 和 addClass() 管样式，show/hide/slide* 做动画。

再加上 .siblings() 这样"为排他思想量身定做"的方法，原生 JS 里十几行的事变成一行。

Bootstrap 则是另一个思路：不写 CSS，只用类名。btn btn-success btn-lg 三个类名就是一个绿色大按钮，table table-striped 就是斑马纹表格——做后台管理这类"不需要独特设计"的页面时，效率非常高。

顺带一句我自己的看法：现在新项目更多用 Vue/React 加 Tailwind 这类方案，jQuery 不像以前那么主流了，但它封装的那套思路（选择器找元素、链式调用、批量操作）和 DOM 操作的基本功是通用的，而且维护老项目时天天用得上。Bootstrap 的栅格和组件类名，到现在很多后台系统里还是标配。
