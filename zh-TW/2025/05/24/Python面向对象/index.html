Study Log

高级编程阶段的第一块内容是面向对象。前面写 Python 基础语法时，类和对象只是最后一节的匆匆一笔；这次把课件 day01～day03 的笔记重新过了一遍，把「类与对象 → 封装 → 继承 → 多态」这条线完整地串起来，最后附上课件 day05 的复习自测题。

一、先搞清楚编程范式

编程范式是一套编程思想的总称，是写程序时采用的基本方法和规范。常见的有面向对象、面向过程、函数式、逻辑式、面向切面等。选对范式能提高代码的可读性、可维护性、可扩展性。

课件用「建房子」把两种范式讲得很直观：

范式 关注点 建房子的比喻 步骤
面向过程 步骤与过程（怎么做） 你自己是施工者 打地基 → 搬砖 → 砌墙 → 刮腻子 → 水电 → 装修 → 入住
面向对象 职责与分工（怎么设计） 你是包工头/指挥 找施工队 → 找装修队 → 签收入住

面向过程的三个特点：

  1. 注重步骤与过程：关注任务的实现过程，而不是职责分工；
  2. 代码结构清晰：需求复杂时代码会变复杂，但结构通常还算清晰；
  3. 开发难度较大：复杂项目没有固定套路。

两者不是对立的，而是相辅相成：面向对象帮我们在宏观上把握、从整体分析；具体到每一步的实现，还是得用面向过程的思维写下去。

课件原话：「面向对象就相当于包工头/领导，把不同的事情分发给不同的团队去完成，最后形成一个整体。」

二、对象是什么

对象是某一个客观存在的事物，它具备能标识自己唯一性的属性和行为。万物皆可对象。

  • 属性：描述这个对象的特征，比如一条狗的姓名、性别、品种、年龄、体重；
  • 行为：描述这个对象能完成的事情，比如干饭、拆家、守家。

类与对象的关系：

  • 类：一个抽象的概念，就是生活中的「类别」。类中的变量叫属性，类中的函数通常叫方法；
  • 对象：类的具体实例，归属于某个类别的个体。

为什么猫头鹰归到鸟类而不是猫类？因为它会飞、有翅膀、会下蛋——这些就是鸟类这个「类」的属性与行为。

定义一个类

四条规则：

  1. 用 class 关键字定义；
  2. 类名建议大驼峰命名（每个单词首字母大写）：student → Student；
  3. 类名后必须跟冒号 :，告诉解释器接下来开始设计类的功能；
  4. 类属性是类中的变量，方法是类中的函数。

有个容易忽略的细节：类在没有实例对象时，类体代码也会预先执行一次。

三、类属性与对象属性

记住这条优先级：对象自己身上的属性 > 类属性。e.name = '德邦' 不是修改类属性，而是在对象 e 上新建了一个属性；类属性只是「共享的默认值」，对象改动的是自己的副本。

__init__ 构造方法

__init__ 是构造方法，每当创建一个类的实例对象时，Python 解释器都会自动调用它。

两个注意点：

  • __init__ 首尾各两个下划线，中间不能有空格；
  • 如果 __init__ 有参数，创建对象时必须手动传参（Employee('李白', 200)），少传会直接 TypeError。

self 到底是谁

self 代表类的实例对象，不是类本身。

从输出就能确认：t 和 t.put() 里的 self 是同一个对象；self.__class__ 则指向它所属的类。

self 并不是 Python 的关键字，理论上可以随便改名也能跑，但请务必保留这个约定——所有读你代码的人都默认第一个参数是 self。

age 写在类里，p1.age、p2.age 都能拿到；name、money 写在 __init__ 里，就各自是每个对象自己的。

Python 内置类属性

属性 含义
__dict__ 类的属性字典（或对象的属性字典）
__doc__ 类的文档字符串，也就是类的「说明书」（# 注释不算）
__name__ 类名
__bases__ 这个类的所有父类组成的元组（object 是所有类的父类）

四、封装与属性隐藏

封装就是把数据封装进自定义的类里，只向外提供必要的功能，隐藏实现细节。好处是保护对象的内部属性和行为不被外部随意修改、删除，提高程序的安全性与可维护性。

生活里的例子：插线板用外壳保护里面的电子元件，电脑用机箱保护硬件，ATM 把钱封装在机器里、只给你一块屏幕操作。

用 @staticmethod 修饰的方法就是非绑定方法，它和普通函数没有区别，没有自动传值的过程，只是「归属于这个类」而已：

课件里的例子把 @staticmethod 的方法写成 def getPwd(self) 然后传整数进去，虽然能跑，但很容易让人误以为静态方法也会自动传值。静态方法不需要第一个 self/cls 参数，这才是它和绑定方法的本质区别。

三种方法对比：

类型 装饰器 第一个参数 自动传值 调用方式
对象绑定方法 无 self 传对象 对象.方法() / 类.方法(对象)
类绑定方法 @classmethod cls 传类 类.方法() / 对象.方法()
非绑定方法 @staticmethod 无 不传 类.方法() / 对象.方法()

一句话记忆：绑定方法会自动把「某个东西」绑到第一个参数上，非绑定方法不会。

七、继承

继承就是「子承父业」：子类能拿到父类的属性和方法。通过继承创建的类叫子类/派生类，被继承的类叫父类/基类/超类。

object 是最顶层的超类，所有类都默认继承它。有一个例外要注意：父类中隐藏的（双下划线）属性，子类继承不了。

单继承

两个常用的判断函数：

  • issubclass(子类, 父类)：判断一个类是不是另一个类的子类或子孙类；
  • isinstance(对象, 类)：判断对象是不是某个类（或它的子类）的实例。

多层继承与 super()

super() 的作用就是「在子类里使用父类的属性或方法」，不用关心父类叫什么名字。

八、多态

多态就是「一个方法可以有不同的表现」。生活里的例子：银行柜台同一个窗口能办存款、取款、买基金，动作都是「办业务」，结果各不相同。

多态的实现有两个前提：

  1. 必须有类的继承；
  2. 子类必须重写父类的方法。

补充：Python 是动态类型语言，多态不强制要求继承——只要不同对象都有同名方法，就能用同一套代码调用它们（也就是常说的「鸭子类型」）。课件把「必须有继承」作为多态的实现前提，是为了和 Java/C++ 那类静态语言的教材保持一致，两者并不冲突。

坑 现象 正确做法
忘了传 __init__ 的参数 TypeError: __init__() missing ... 创建对象时把参数补齐
__init__ 写成 _init_ 构造方法不会执行 首尾各两个下划线，中间无空格

小结

  • 面向对象是「设计问题」的范式，面向过程是「解决问题」的范式，两者配合使用；
  • 类属性共享、对象属性独有，查找顺序是实例 → 类 → 父类；
  • 封装靠双下划线隐藏 + property 代理，双下划线只是改名，不是安全边界；
  • 绑定方法自动传值（对象传 self、类传 cls），非绑定方法不传；
  • 继承解决复用，super() 解决父类调用，MRO 解决多继承的查找顺序；
  • 多态 = 继承 + 方法重写，让同一个方法调用有不同的表现。
