JavaScript 基础：变量、类型、流程控制与 DOM

前言

HTML 是结构、CSS 是表现，JS 是行为——页面上所有"会动、会响应"的东西都是它干的：点了按钮变色、鼠标经过高亮、图片轮播、定时弹窗。

课件用 day12 到 day19 共 8 天讲完 JS 基础，路线很清楚：

graph LR
    A[变量与数据类型] --> B[类型转换/运算符]
    B --> C[流程控制与循环]
    C --> D[数组与函数]
    D --> E[内置对象 Math/Date/String]
    E --> F[DOM 获取元素与事件]
    F --> G[对象与构造函数]

前面几步是"编程语言通用基础"，DOM 才是 JS 在前端真正的用武之地——用代码去操作页面上的标签。

说明：这一篇依据的是课件 day12–day19 的案例代码（这几天的 笔记 目录是空的），所以文中的表格、方法清单和示例都直接来自案例文件，而不是课件讲义。

一、JS 的历史与书写方式

历史：JavaScript 由 Netscape 的 Brendan Eich 在 1995 年用 10 天设计出来，最初叫 LiveScript，为了蹭 Java 的热度改名 JavaScript（两者没有关系）。它后来被 ECMA 标准化为 ECMAScript，我们说的 ES5、ES6 就是它的版本。

二、变量

  • 声明用 let（ES6）或 var（旧写法），课件统一用 let；
  • 变量名见名知意，多个单词用小驼峰 userName；
  • 变量可以先声明后赋值：let a; a = 10;；
  • console.log() 是给我们自己看的输出，会打印在浏览器的控制台里。

十一、DOM：用 JS 操作页面

DOM（Document Object Model，文档对象模型）把整个 HTML 页面变成一棵由对象组成的树，JS 通过这棵树去读写页面：改文字、改样式、加事件。

获取元素的 7 种方式

两个必须记住的差别：

  • getElementById 返回单个元素，其余返回集合（伪数组）——伪数组有 length、能用索引取值，但不能用数组的方法（比如 forEach 在部分老浏览器里不行），所以要 for 循环遍历；
  • 集合是动态的：页面上的元素变化后再去取，结果也会跟着变。

十二、对象

对象有两大特征：属性和方法。
姓名、年龄、性别是属性（名词）；唱歌、跳舞、敲代码是方法（动词，本质就是函数）。

四种创建方式（一步一步进化）

new 到底做了什么（四个步骤）：

  1. 在内存里创建一个空对象；
  2. 让构造函数里的 this 指向这个新对象；
  3. 执行构造函数里的代码（给 this 加属性、加方法）；
  4. 返回这个对象（所以构造函数里不用写 return）。

把方法放到原型上

十三、综合案例：tab 栏（两个排他思想）

tab 栏是这一阶段所有知识点的汇总，案例里的完整版这么做：

  1. 结构：外面一个 .box，里面 .hd 放 4 个 span（标题），.bd 放 4 个 li（内容）；.current 类控制"谁被选中"；
  2. JS：给每个 span 用自定义属性存下自己的索引；
  3. 点击时做两次排他——先清掉所有 span 的 current，给自己加上；再清掉所有 li 的 current，给索引相同的那个 li 加上。

案例里 list[num] 中的 num 是 getAttribute 返回的字符串，这里靠 JS 自动转成数字才没出错。换成 === 比较或做数学运算时，就必须先 parseInt(num)——这是这类代码最常见的隐藏 bug。

小结

JS 基础这一阶段，我觉得可以压缩成四句话：

  1. 数据先分清类型——typeof、真假值表、=== 优于 ==，能避开一半的低级错误；
  2. 流程控制决定"怎么走"——if 管区间，switch 管枚举，循环管重复，三元管二选一；
  3. 函数是封装的最小单位——形参进、return 出，return 之后不执行；对象则是把"属性 + 方法"打包，批量生产用构造函数，方法放原型省内存；
  4. DOM 是 JS 在前端的战场——获取元素 → 绑定事件 → 用 this 操作自己 → 改内容/样式/属性，再加上「排他思想」和「定时器」这两个套路，页面就能动起来了。

下一阶段是 jQuery 和 Ajax——用更少的代码做同样的事，以及让页面能和服务器交换数据。
