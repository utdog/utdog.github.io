Study Log

作为一名刚接触Hexo的博主，我被它简洁高效的静态博客框架所吸引。不需要繁杂的数据库，只要一套 Markdown + 主题，就能轻松搭建个人网站。从第一篇“Hello, Hexo”开始，我便迫不及待地将学习心得、操作笔记、页面设计思路依次写入，记录每一次配置主题、更换插件或优化排版的点滴过程。在 Hexo 上，每一次命令行的执行、每一次配置文件的改动，都会化作页面中的一行行文字和一张张截图，见证自己对前端渲染原理与静态站点部署技术的不断探索。
可以查看文档以获得更多信息documentation，如果你在Hexo中遇到什么疑难杂症可以在 troubleshooting中找到答案，或者在中GitHub问我。
下面是一份快速上手指南，帮助你在已有的 Hexo 博客中创建新文章、启动本地预览，并通过常用命令生成与部署站点：

快速上手

安装完Hexo后，新建一个文件夹打开GitBash或者PowerShell，执行下列命令，Hexo将会在指定文件夹新建所需的文件

启动服务

默认监听 http://localhost:4000；

实时监测文件改动，保存后刷新页面即可预览最新效果。

生成静态文件

将 Markdown、主题模板和配置文件一起编译为最终的静态页面；

输出目录为 public/，包含所有 HTML、CSS、JS、图片等资源。

更多在这里: Generating

部署到远程站点

更多在这里: Deployment

第一次使用想要部署到远程仓库（比如Github储存库）

需要与远程用Git与Github注册的用户名和邮箱绑定

创建一个新的文章

会在 source/_posts/ 目录下生成一份带有日期和标题的 Markdown 文件；

打开该文件，按需补充前置的 YAML 头信息（title、date、tags），以及正文内容。

更多在这里: Writing

常用命令速览

命令 作用
hexo clean 清除生成的静态文件及缓存
hexo g 生成（generate）静态文件
hexo s 启动（server）本地预览
hexo d 部署（deploy）到远程仓库
hexo n "标题" 新建（new）一篇文章

结束语

从“hexo new”的兴奋，到“hexo d”的成就，每一次命令都在告诉我：在静态博客的世界里，写作与部署可以如此简单、高效。希望这份指南能帮助你快速上手，把你的学习笔记、项目日志和设计思路，一一记录在 Hexo 博客上，打造属于自己的在线知识库。
