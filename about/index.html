关于我

大家好，我是站长。自从接触 Hexo 以来，我便被它轻量、高效、可定制的特性深深吸引。从主题二次开发、插件调试，到部署到 GitHub Pages，我乐此不疲——不仅记录了技术细节，更收获了不断试错与成长的成就感。

关于博客

这里是我的技术日志与设计笔记汇聚地，我会分享：

  • Hexo 深度玩法：主题定制、插件开发、构建优化、自动化部署；
  • 前端实践心得：HTML/CSS/JavaScript 效率提升小技巧；
  • 项目实战记录：校园实训、开源项目、个人练手；
  • 工具链与工作流：Git、命令行简述。
  • Python 全栈开发：在这里，我不仅分享前端与静态站点的探索，也会深入记录 Python 全栈开发的实战历程。从最基础的语法入门、到数据结构与算法的高级编程，再到爬虫项目中对网页解析与数据清洗的应用，我一步步积累了扎实的后端功底。
    • 基础语法 & 编程范式：掌握变量、流程控制、函数与面向对象等核心概念；
    • 高级编程：理解装饰器、生成器、上下文管理、并发与异步编程；
    • 爬虫开发：基于 Requests、BeautifulSoup、Scrapy 等框架，设计分布式爬虫与反爬策略；
    • Web 框架：熟悉 Django 的 MTV 架构，能够从模型层、视图层到模板层全流程搭建企业级 Web 应用；
    • 数据库 & 可视化工具：MySQL 负责设计表结构、编写复杂 SQL 与性能优化，Navicat Premium 通过可视化界面快速进行数据建模、查询与迁移操作。
      希望通过这些内容，帮助同样喜爱静态网站和前端自动化的小伙伴少走弯路。

写作宗旨

  • 透明开放：不藏私，Bug、报错、踩坑、调试过程一并输出；
  • 循序渐进：从入门到进阶，每篇文章都有“核心思路＋实战演示”双重收获；
  • 终身学习：技术日新月异，保持好奇，持续更新，用记录见证成长。

技术栈

  • 静态博客：Hexo + Markdown + 自定义主题
  • 前端基础：HTML5、CSS3、JavaScript
  • 构建部署：Git + GitHub Pages
  • 辅助工具：VSCode、Node.js、npm
